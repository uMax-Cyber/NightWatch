# Contributing

1. Fork the repo
2. Create a feature branch (`git checkout -b feature/amazing`)
3. Commit changes (`git commit -m 'feat: add amazing'`)
4. Push (`git push origin feature/amazing`)
5. Open a Pull Request

## Code style
- Python: PEP 8, type hints where possible
- Bash: `set -euo pipefail`, meaningful error messages
- All scripts must be idempotent (safe to run twice)
